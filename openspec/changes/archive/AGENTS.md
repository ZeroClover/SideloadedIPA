# Historical evidence scope

Files here record past proposals, decisions, spec deltas and acceptance evidence.
Their commands, file paths, version pins, compatibility plans and task checkboxes
are snapshots, not current Agent instructions or proof of current acceptance.

Use them only when the task needs provenance. Preserve recorded evidence; current
requirements live in openspec/specs/ with relevant active deltas, and current
operating procedures are routed from the root AGENTS.md.
